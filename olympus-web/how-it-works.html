How it works

From nothing to a running project

There is no account, no key to paste and no service to sign up for. Olympus drives the opencode agent you already have, against a model you already run.

Home / How it works

How it works

  1. 1

    Check the prerequisites

    Node 18 or newer, and opencode on your PATH. Those two are the whole list, and the compatibility note says which opencode version to expect.

  2. 2

    Point it at a model

    Olympus finds the loopback servers already running on your machine and lists what each has loaded. Providers configured inside opencode show up in the picker as well.

  3. 3

    Open a project

    Add a folder to the project library. Olympus spawns and supervises opencode serve for it, switching the daemon’s working directory when you open a different project.

  4. 4

    Review, then run

    Read the diff, accept or reject, approve commands separately. Then start the detected project command and watch it in the embedded preview.

Before you start. Check the requirements first — if the model you want to use is not already running locally, there is nothing for Olympus to connect to. The daemon shuts down cleanly when you exit.
