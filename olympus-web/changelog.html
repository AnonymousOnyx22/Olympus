0.1.0

28 September 2026

First public build

Tested against opencode 1.18.x. Platforms: macOS on Apple Silicon and Intel, Windows 10 and 11, Linux x64. Licence $49 one-time, or free to keep as 0.1.0.

What works

  • One supervised agent per project. Each project gets its own opencode serve on 127.0.0.1, on a randomised high port, with a fresh HTTP basic-auth credential generated for that launch. Switching projects does not stop the other one, and busy state stays visible in the project tree.
  • Local model discovery. Ollama, LM Studio, vLLM, llama.cpp and any other loopback OpenAI-compatible server are found automatically and listed with what each has loaded. Providers already configured in opencode appear in the picker as well.
  • Three views on one session. Agent, Code and Thread. Same session and same composer draft across all three; switching never restarts a run or discards a pending approval.
  • Streamed reasoning, tool cards and an agent-output console, with expandable per-tool output and an inline diff on every tool call that touched a file.
  • Edit review. Edits made through the edit tool stop in a diff viewer and stay there until accepted. Shell commands ask for separate approval.
  • Project library. Search, sort, list or grid, watch folders, pin, reveal in the file manager, hide, remove. A folder that has gone missing is reported as missing rather than silently dropped.
  • Git in the window header. Branch, tracking branch, changed files, ahead and behind. Commit and push are separate buttons and nothing is committed for you.
  • Run and live preview. Starts the detected project command and embeds a preview of your real localhost dev server next to the agent changing it.
  • A real interactive shell, not a scrollback of a log.
  • Offline licence validation. No activation call, so the app works with the network switched off.

What is not in this build

  • No auto-update mechanism yet. Builds are downloaded by hand, which is why every 0.x update is a manual step for now.
  • No 1.0. The interfaces the app drives in opencode may change without notice, and when they do this build will say so rather than pretending to work. See the compatibility note.
  • No Linux ARM build, and no distro packages. The AppImage is the only Linux artefact and it is tested on one distribution.
  • No import or export of projects, threads or settings. Moving machines means setting the project list up again.
  • No localisation. Interface strings are English only.
  • No crash reporting, because there is nowhere to send it. A crash is yours to report at support@example.com.

Known rough edges

  • Model discovery polls. A server started after Olympus is already open may need a refresh to appear.
  • The live preview is a plain frame of your dev server. Anything that depends on a service worker or a cross-origin frame will not render in it.
  • Very large diffs are slow to open. There is no virtualised diff view yet.

Download 0.1.0

Pre-1.0 means the interfaces may move. Every build in the 0.x line keeps working against the opencode versions it was tested with, and each release here records which those are. A future 1.0 will be a one-off upgrade priced before it ships, not a subscription and not a repurchase. The reasoning is on the pricing page.
