The latest release.

0.1.0

28 September 2026First release

Made for your everyday work

  • Keep projects together and let each agent work independently.
  • Choose from the models available on your computer.
  • Switch between Agent, Code, and Thread without losing your place.
  • Review proposed edits and approve commands separately.
  • Browse files, track changes, and preview your project in one workspace.
  • Use your licence without signing into an account.

Good to know

  • Download new releases manually; automatic updates are not available yet.
  • Project lists and settings need to be set up again when moving to a new computer.
  • The interface is currently available in English.
  • If you start a model after opening Olympus, you may need to refresh the model list.
  • Large changes can take longer to open, and some projects may need to be previewed in a separate browser.

Available for macOS, Windows, and 64-bit Linux. Check the setup requirements.
