Features

A clearer way to build

Everything you need to follow the work and keep your projects moving.

Home / Features

Runs the models you already have

Bring your choice of compatible agent and model provider. Olympus gives your work a shared home, with projects, conversations, and changes together.

Keep every project moving

Each project can keep working independently. Move to another project and see which agents are still busy.

Views for each kind of work

Follow a task in Chat, see parallel sessions in Agents, explore files in Code, or read the conversation in Thread. Switch views without losing your place or your draft.

Reviewable edits

Review proposed file edits before accepting them. Commands need separate approval because they can also change your files.

See the work as it happens

See what your agent is doing, inspect its changes, and open more detail when you need it.

Project library

Find, organise, and pin your projects. Open a folder quickly and see when a project has moved or is no longer available.

Keep track of changes

See what has changed in your project. Saving a version and publishing it are separate actions that you choose.

Run and live preview

Run your project and see the result alongside the agent working on it.
