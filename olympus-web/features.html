Features

Runs the models you already have

Discovers models on Ollama, LM Studio, vLLM, llama.cpp and other loopback OpenAI-compatible servers, and lists what each one has loaded. Providers already configured in opencode appear in the model picker too.

Per-project agents that keep running

Every project has its own agent process. Move to another project and the previous one keeps working, with its busy state still shown in the tree.

Three views on one session

Agent for the live transcript, Code for the file explorer, editor and run controls, Thread for a conversation-forward read. Same session, same composer draft. Switching never restarts a run or discards a pending approval.

Reviewable edits

Edits made through the edit tool stop for review in a diff viewer. Nothing is written to disk until you accept. Shell commands require separate approval, because they can change files.

Live tooling

Streamed reasoning, tool-call cards with expandable output and inline diffs, an agent-output console, and a real interactive shell rather than a log dump.

Project library

Search, sort, list or grid, watch folders, create, pin, reveal in the file manager, hide or remove. When a folder is gone, the app says so instead of pretending.

Git in the header

Branch, tracking branch, changed files, ahead and behind, always visible. Commit and push are separate, explicit actions. Nothing is committed for you.

Run and live preview

Start the detected project command and watch the result in an embedded preview of your real localhost app.

None of this is new to opencode. It is the same agent, in a window that shows you its work. A row-by-row comparison is on the home page, and it gives the command line its due.
