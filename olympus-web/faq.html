Getting started

Okay, so what actually is Olympus?

A desktop workspace for AI coding agents. It brings your projects, the running agent, the code, and a live preview into one screen, with several projects open and working at once instead of a single chat window.

What do I need to get started?

A supported computer, a project folder, and a compatible agent and model ready to use. The setup checklist covers the software you need.

Can I use it now?

Not yet. Olympus is still in development, and nothing is for sale. Join the waitlist to hear the moment a build is ready to try.

Using the agent

What can the agent change without asking?

In Ask mode, file edits and commands require approval. Auto edit allows file edits while commands still ask. Full access allows edits and commands without asking. Choose the mode in the app before giving an agent a task. Learn about your controls.

Which models work with Olympus?

Olympus is independent of any one provider. Use a model supported by your chosen agent and setup, whether it runs locally or through a connected cloud provider.

What happens to my projects if I uninstall?

Nothing. Your projects, your code, and your git history live where you put them, not inside Olympus. Uninstalling removes the app, not your work.

Your data & security

Does everything run on my computer?

With a model running on your computer, your AI work stays there. If you choose a cloud provider, your requests go to that provider instead. Olympus does not track your activity or require an account.

Is there a subscription?

That has not been decided. What is certain is there will be no hidden recurring charge you were not told about up front; pricing will be published before anything is sold.

Support

What if it isn't the right fit?

Join the waitlist and you will be told when a build is ready to try before anything is for sale, so you can decide for yourself whether it fits.

How do I report a bug or a security issue?

Ordinary bugs: email {{contact.supportEmail}}, or open a public issue if you'd rather have the fix in the open. Security problems: email {{contact.securityEmail}} instead, and please don't open a public issue for anything exploitable.
