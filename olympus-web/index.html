Read the setup guide ↗

What do I need to get started?

A supported computer, a project folder, and a compatible agent and model ready to use. The setup checklist covers the software you need.

Does everything run on my computer?

With a model running on your computer, your AI work stays there. If you choose a cloud provider, your requests go to that provider. Olympus does not track your activity or require an account.

Can I really keep using it for free?

Yes. The current release has all features and no time limit. The $49 licence adds ongoing updates throughout the 0.x line and email support. See the complete pricing terms.

What can the agent change without asking?

Proposed file edits wait for your approval. Commands ask separately because they can also change files. Review both before accepting. Learn about your controls.

Which models work with Olympus?

Olympus is independent of any one provider. Use a model supported by your chosen agent and setup, whether it runs locally or through a connected cloud provider.

What if it isn’t the right fit?

Try the free release first. If you buy a licence, the refund window is 14 days. The refund policy explains the process.
