    More about agents

    A window per conversation

    Open as many as your machine can handle. Each shows streamed reasoning, tool calls you can expand and the live todo list.

    Queue the next message

    Add another message while an agent is working. It goes out when the agent is ready, and you can remove it before then.

    Stop and recover

    Stop any agent from its header. If one fails partway, a Continue button picks the work back up.
