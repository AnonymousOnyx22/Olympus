FAQ

Questions.

What is Kern?

A desktop app that connects all your AI agents and models in one workspace. You work on separate projects at the same time, each in its own window, and choose a model per window.

Is Kern an AI?

No. It is not an agent or a model. It is the app you connect them to, with the controls around them: review, approvals, projects and keys.

Which models can I connect?

Claude, GPT, Gemini, Kimi, Grok, Llama, Mistral and models running on your own computer, depending on what you connect: a local server, a key (Gemini, Mistral, Hugging Face, OpenRouter, OpenCode Zen), or the Claude and Codex command line tools.

Do I have to pick one?

No. Each window has its own model, so you can use several at once, on the same project or different ones.

Can several agents really work at the same time?

Yes. Every conversation is its own window, and every window belongs to a project. Run as many side by side as your machine can handle.

Can I download it?

Not yet. Kern is in private development and is not publicly distributed. There is no price, waitlist or release date.

Does my code leave my computer?

Not through Kern. If a window uses a model on your computer, nothing leaves it. If it uses a hosted model, your prompts and the files the agent reads go to that provider, as they would anywhere. See Privacy.

Can an agent change my files without asking?

Only if you let it. By default edits and shell commands ask first. Full access is a deliberate choice you make per agent.

Do I need an account?

No. There is no Kern account and no login.

Why is there no mobile version?

Kern is a desktop tool that needs your project folders and a terminal. It is not designed for small screens.
