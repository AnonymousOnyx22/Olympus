Security

Built to stay on your machine.

Each claim below is something the app enforces, not a promise.

The interface cannot reach the networkAll requests go through the app's main process, and the packaged interface ships with a content security policy of connect-src 'self'.
The interface cannot touch your systemContext isolation is on, Node integration is off, and the interface gets a small typed API.
Agents ask firstEdits, shell commands and access outside the project are set to ask by default. Looser modes are your choice, per agent.
Added endpoints stay localServers you add inside Kern must be on this computer (loopback addresses).
Keys are encryptedSaved values use your operating system's secret storage and are only decrypted in the main process.
No sharing, no automatic updatesSharing and automatic updates are turned off for the agents Kern runs.
No telemetryNo analytics, crash reporting or account. This website sets no cookies.

Limits, plainly

  • Builds are not signed yet, so Windows and macOS will warn on first launch.
  • A hosted model sees whatever the agent sends it. Kern cannot change that.
  • The Claude and Codex command line bridge receives every saved connection, regardless of per project settings.
