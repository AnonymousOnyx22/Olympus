What each project receives

Only what you allow.

Every project gets the connections you have allowed for it, as environment variables. Toggle the boxes above and watch these change. Only the names appear here; the values never show up in a chat.

How it works

From a pasted key to a working project.

Encrypted on this computer

Secret values are encrypted with your operating system's own secret storage: DPAPI on Windows, Keychain on macOS, libsecret on Linux. They are only decrypted inside the app's main process.

Tested where possible

Saving runs a real check against the service for Stripe, SendGrid, Netlify, Vercel, Cloudflare Pages, Render, OpenRouter, Mistral, Hugging Face. The rest are saved but never claimed to work: they show "Saved, no test". A failed check says what was rejected, and the result is dropped the moment a value changes so it can never describe stale input.

Allowed per project

Every project gets each saved connection unless you uncheck it on that connection's page. Unchecked projects get nothing. A running agent picks up the change the next time it starts.

The model never sees the value

Generated code reads process.env.STRIPE_SECRET_KEY. The agent uses the variable; the raw key is not part of the conversation, so a model provider never receives it from Kern.

One exception: if you use the Claude or Codex command line tools as a model, their local bridge receives every saved connection, whatever the per project boxes say.
